# 🎓 Admission Management System

A modern web-based Admission Management System that simplifies the student admission process. This project allows students to register, apply for admission, and track their application status, while administrators can manage applications and student records efficiently.

---

## 📌 Features

### 👨‍🎓 Student Module

- Student registration and login
- Online admission form submission
- Upload required documents
- View admission status
- Profile management
- Application history

### 👨‍💼 Admin Module

- Secure admin login
- Manage student applications
- Approve or reject applications
- Search and filter records
- Generate reports
- Dashboard with statistics

### 📊 Dashboard

- Total students
- Pending applications
- Approved admissions
- Rejected applications
- Recent activities

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/pallavipallavidn60-glitch/Admission-_system.git
```

### 2. Move the project to XAMPP

Copy the project folder to:

```text
C:\xampp\htdocs\
```

### 3. Start XAMPP

Start:

- Apache
- MySQL

### 4. Import the database

- Open phpMyAdmin
- Create a new database
- Import the SQL file

### 5. Run the project

Open:

```text
http://localhost/Admission-_system
```
